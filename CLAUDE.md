## Как устроен код

React 18 + TypeScript + Vite + Tailwind CSS 3 + three.js. Сборка: `npm install && npm run build`.

- `src/content.ts` — **все тексты и данные** (врачи, отзывы, услуги, цены, акция, факты). Менять данные — здесь.
- `src/i18n.tsx` — перевод на казахский (словарь «русский текст → казахский») и переключатель РУС/ҚАЗ.
  Любой новый текст на сайте оборачивать в `t('…')` и добавлять перевод в словарь `KZ`.
  Перевод сделан ИИ — клиника ещё не проверила.
- `src/App.tsx` — порядок блоков на странице, первый экран.
- `src/components/Sections.tsx` — почти все блоки (меню, акция, владелец, цифры, услуги, отзывы, цены, вопросы,
  форма записи, подвал, нижняя панель на телефоне).
- `src/components/Doctors.tsx` + `Carousel.tsx` — карусель команды (и отзывов): свайп, мышь, стрелки.
- `src/components/Tooth3D.tsx` — 3D-зуб из частиц на первом экране (грузится отдельно, lazy).
- `src/components/Chart3D.tsx` — 3D-диаграмма; **скрыта**, пока `chart.demo = true` (сейчас там примерные числа).
- `public/photos/` — фото сотрудников (из 2ГИС), `public/video/promo.mp4` — ролик из рекламы клиники,
  `public/og.jpg` — превью ссылки для WhatsApp/Telegram, `favicon.svg` — иконка.
- Цвета (фирменные клиники: чёрный + жёлтый) — в `tailwind.config.js`. Имена токенов исторические:
  `mint` = жёлтый #F5D43B, `teal` = тёмно-жёлтый для текста на светлом, `ink` = чёрный.
- В `index.css` для `html, body` стоит `overflow-x: clip` (не `hidden`) — иначе ломается `position: sticky`.

## Что на сайте сейчас

Первый экран с 3D-зубом и кнопкой «Болит зуб? Позвоните сейчас» → бегущая строка → акция с видео
(«Заплати за лечение — чистку получи в подарок») → владелец → «Клиника в цифрах» → команда (карусель,
кнопка «Записаться к врачу») → услуги → отзывы (карусель) → цены + частые вопросы → форма записи
(открывает WhatsApp с готовым сообщением, можно выбрать врача) + карта → подвал.

## Правила (важно)

- **Ничего не выдумывать**: отзывы, цифры, награды, цитаты владельца, стаж, даты акций. Только реальные данные
  от клиники или из 2ГИС. Нет данных — блок скрываем (а не ставим заглушку в [скобках] на виду).
- Отзывы — настоящие из 2ГИС, фамилии сокращены до буквы, текст не переписывать (казахские оставлять как есть).
- Имена сотрудников — с бейджиков на фото и из отзывов. Неизвестное имя → подпись должностью («Врач клиники»).
- Не брать чужую музыку, фото, дизайн. Отдельная «версия-история» (story.html) была сделана и **удалена
  по просьбе пользователя** — не возвращать без запроса (она есть в истории git).
- Проверять изменения в браузере (Playwright) на компьютере и телефоне, в т.ч. узкий 320 px, и на обоих языках.
